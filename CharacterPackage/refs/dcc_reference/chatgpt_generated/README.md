# YUNA ChatGPT DCC Reference Set

These images are AI-generated reference sheets for human DCC production. They are not final 3D assets.

## Files

- `yuna_dcc_turnaround_3view.png`: front, side and back orthographic character reference.
- `yuna_dcc_face_expression_sheet.png`: facial expression and mouth-shape reference for blendshape sculpting.
- `yuna_dcc_weapon_orthographic_sheet.png`: weapon front/side/back/detail orthographic reference.
- `yuna_dcc_material_texture_reference.png`: material, palette and texture callout reference for PBR/URP texturing.

## Usage

Use these as inferred references for Blender, ZBrush, Maya, Substance Painter and Unity production. The locked identity source remains `../../front_rgba/yuna_front_rgba.png`.

## Boundary

These references reduce ambiguity for human modeling, retopology, UV, material and rigging work. They do not replace manual sculpting, final topology, weight painting, blendshape cleanup or Unity Avatar validation.
