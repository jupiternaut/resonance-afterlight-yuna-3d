## Working Style

In the YUNA 2.5D-to-3D project, Codex should work like a precision scraping
loop:

- use `AGENTS.md` and repo Markdown as hard standards;
- modify one high point per iteration;
- verify with tests, reports, and screenshots;
- never accept numeric metrics when visual sanity fails;
- keep `CharacterPackage/semantic_layer_v8` immutable unless explicitly told
  otherwise.
