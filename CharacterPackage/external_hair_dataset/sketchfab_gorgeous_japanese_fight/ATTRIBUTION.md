## Local Use

The original GLB is stored as:

```text
source/gorgeous_japanese_fight.glb
```

The extracted pink-hair probe is stored as:

```text
extracted/pink_hair_segment_probe.glb
extracted/pink_hair_segment_probe.obj
extracted/pink_hair_segment_probe.blend
```

The extracted probe is a derivative local-study artifact. It is intended only as
a prior/reference for YUNA hair mass, scalp anchors, and flow direction. It is
not accepted as YUNA replacement hair or final production topology.
